# Prompt Snippet Manager

ChatGPT や Codex などへ頻繁に入力する定型プロンプトを登録し、カテゴリから選んでクリップボードへコピーできるデスクトップツールです。

## 主な機能

- カテゴリ別のプロンプト一覧表示（「すべて」を含む）
- 複数行のプロンプト本文表示
- プロンプトの新規登録、編集、削除
- ボタン一つでクリップボードへコピー
- タイトル・本文・カテゴリ・タグの検索
- タイトル、使用回数、最終使用日時による並び替え
- お気に入り登録とお気に入りのみの絞り込み
- `{symbol}` のようなテンプレート変数への入力値反映
- JSON ファイルへの自動保存
- コピー回数と最終使用日時の記録
- 壊れた JSON を検知した場合のクラッシュしない読み込み

## 起動方法

Python 3.10 以降を用意し、プロジェクト直下で次を実行します。

```powershell
python main.py
```

追加パッケージは不要です。GUI には Python 標準の Tkinter を使用しています。

## データ保存場所

プロンプトは `data/prompts.json` に保存されます。ファイルが存在しない初回起動時には、動作確認用の初期データが自動生成されます。

初期データには、開発・EA研究・文章作成・その他の16件を収録しています。要件整理、エラー調査、テスト設計、文章改善、比較検討など、用途を限定しないプロンプトも含まれます。EA研究向けには、戦略仕様の整理、バックテスト設計、頑健性検証、リスク管理レビューを収録しています。

JSON が壊れている場合はエラーをステータスバーに表示し、アプリは空の一覧で起動します。必要に応じて JSON を修正または削除してから再起動してください。

## 基本的な使い方

1. 左側でカテゴリを選びます。
2. 中央の一覧からプロンプトを選び、本文を確認します。
3. `コピー` を押すと本文がクリップボードへ入ります。
4. `新規`、`編集`、`削除` で登録内容を管理します。
5. 検索欄、並び替え、お気に入り絞り込みで目的のプロンプトを探せます。

本文に `{symbol}` や `{strategy}` の形式で変数を記述しておくと、プロンプトを選択した時点で本文の直下に入力欄が表示されます。本文を確認しながら値を入力し、`コピー` を押してください。入力後の置換結果だけがクリップボードへコピーされ、保存されている本文は変わりません。

### `{symbol}` のサンプル

初期データには「シンボル別コードレビュー」が登録されています。本文は次のようになっています。

```text
{symbol} の現在の実装をレビューしてください。
重大な不具合、保守性の問題、設計上の問題を優先して指摘してください。
```

このプロンプトを選ぶと、本文の直下に `symbol` の入力欄が表示されます。そこへ `EURUSD` と入力して `コピー` を押すと、次の内容がクリップボードへコピーされます。

```text
EURUSD の現在の実装をレビューしてください。
重大な不具合、保守性の問題、設計上の問題を優先して指摘してください。
```

複数の変数を使う場合は、本文に `{symbol}` と `{strategy}` のように記述します。変数名は英字またはアンダースコアで始め、英数字とアンダースコアを使えます。同じ変数を本文中で複数回使った場合は入力値を共有します。未入力の変数がある場合はコピーされず、最初の未入力欄へフォーカスします。`Tab` と `Shift+Tab` で入力欄を移動でき、`Enter` でもコピーできます。

タグはカンマ区切りで入力します。タグも検索対象になります。

タイトルと本文は必須です。カテゴリを空欄にした場合は「その他」に分類されます。
